Local-first icon resolution

One query.
A local icon path.

Appicon gives Waybar, Rofi, scripts, and AI tools a dependable path to the right icon—without pushing download logic into every consumer.

Install Appicon Latest release
appicon — resolve
$ appicon resolve firefox
/home/me/.cache/appicon/svgl/firefox.svg

$ appicon resolve --json missing-app
{"query":"missing-app","path":null}

Build it. Resolve it.

Install from source with Go, or choose a signed archive from the latest release.

git clone https://github.com/bolens/appicon.git
cd appicon
make build
./bin/appicon resolve firefox
