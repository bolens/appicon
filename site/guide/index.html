Common tasks

Use Appicon.

Start with the application name shown in your launcher. Appicon prints a local file path.

Find one icon

Use the application name that you see.

appicon resolve firefox

Create a small PNG

Use this command for a bar or menu that cannot display SVG files.

appicon resolve --format png --size 24 firefox

Work offline

Offline mode uses only icons Appicon already has.

appicon resolve --offline firefox

Correct a wrong match

Map your application name to a known icon.

appicon override set my-browser firefox

If Appicon prints nothing

Appicon did not find the icon. Try a shorter name or check the spelling. Keep a fallback icon in your bar or launcher.
