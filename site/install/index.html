Install

Install Appicon.

Choose your operating system. The page remembers your choice on this device.

Current release: __SITE_VERSION__

Arch Linux

Install the ready-made AUR package.

yay -S appicon-bin

Nix

Install the ready-made flake package.

nix profile install github:bolens/appicon#appicon-bin

Download the macOS archive

Open the latest release and choose the archive for your Mac processor. Move the appicon file to a directory on your PATH.

Open the latest release

Download the Windows archive

Open the latest release and choose the Windows archive. Extract appicon.exe to a directory on your PATH.

Open the latest release

Check the installation

appicon version
