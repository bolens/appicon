Architecture

How Appicon finds an icon.

Every request moves through an ordered list of sources. Appicon checks local overrides and desktop files first. It uses an enabled remote source only when local sources miss.

What the map shows

The topology follows requests from the CLI, MCP server, or optional daemon into one shared resolver. It also shows the cache and each icon source.

Who needs the map

Use it when you integrate Appicon, add a source, debug resolution order, or contribute code.

Open the interactive topology

The diagram supports light and dark themes, keyboard navigation, search, and export.
